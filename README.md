## 📖 About

A modern, visually appealing, and high-converting **landing page** designed for an online course.

Clean layout, smooth scrolling, and strong Call-to-Action sections — built to maximize user engagement and drive enrollments. Highlights pixel-perfect, responsive design using **Tailwind CSS**.

---

## ✨ Features

- 🎨 **Modern UI/UX** — clean, professional design focused on conversion
- 📱 **Fully Responsive** — perfect on desktop, tablet, and mobile
- 🏃 **Smooth Scrolling** — seamless navigation between sections
- ✨ **Complete Sections** — hero, curriculum, instructor bio, and testimonials
- 🎯 **Strong CTAs** — strategic call-to-action buttons for user enrollment

## 🚀 Run Locally

```bash
# Clone the repository
git clone https://github.com/Mahak-012/online-course-landing-page.git

# Go to project directory
cd online-course-landing-page

# Install dependencies
npm install

# Start development server
npm run dev
```

> If it's pure HTML/CSS — simply open `index.html` directly in your browser!
