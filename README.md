📖 About The Project
A modern, visually appealing, and high-converting landing page designed for an online course. It features a clean layout, smooth scrolling, and strong Call-to-Action (CTA) sections to maximize user engagement. This project highlights my ability to create pixel-perfect, responsive designs using Tailwind CSS.

✨ Key Features
🎨 Modern UI/UX: Clean and professional design with a focus on conversion.
📱 Fully Responsive: Looks perfect on desktops, tablets, and mobile devices.
🏃 Smooth Scrolling: Seamless navigation between different sections of the page.
✨ Appealing Sections: Hero area, course curriculum, instructor bio, and testimonials.
🎯 Strong CTAs: Strategic call-to-action buttons to drive user enrollment.

🚀 Run Locally
To run this project on your local machine, follow these steps:



Clone the project
git clone https://github.com/Mahak-012/online-course-landing-page.git
Go to the project directory
bash

cd online-course-landing-page
Install dependencies (if using Tailwind/Vite setup)
bash

npm install
Start the development server
bash

npm run dev
(If it's pure HTML/CSS, simply open the index.html file in your browser)
